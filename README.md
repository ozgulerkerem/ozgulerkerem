## 📌 Featured Projects

### 📈 Rossmann Retail Sales Forecasting

End-to-end retail sales forecasting project using leakage-safe historical features, time-based validation, LightGBM, and XGBoost.

- Built calendar, promotion, competition, lag, and rolling sales features
- Used a 48-day time-based validation period instead of random splitting
- Compared a historical baseline, LightGBM, and XGBoost
- XGBoost achieved **12.32% RMSPE**, reducing MAE by approximately **76%** compared with the baseline
- Generated forecasts for **41,088 future store-day observations**

📁 Repository:  
https://github.com/ozgulerkerem/rossmann-sales-forecasting
